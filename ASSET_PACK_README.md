# Sonic Architecture essential renderer assets

This is a curated supplement for the lightweight Gemini Flash code package. Copy the `public/assets/` folder into the local project at the same path; the original directory structure is preserved.

Included: `public/assets/hdris/studio_warm.hdr` for warm environment lighting; model kits for a hanging industrial lamp, modern arm chair, dining table, and potted plant; and material maps for raw concrete, plaster, terrazzo, and light oak.

Use these files at runtime in your renderer. Keep attribution and license details from the original repository's `THIRD_PARTY_ASSETS.md`. Do not upload these assets into a prompt or ask Gemini Flash to visually inspect them; tell it their paths and semantic roles instead.
